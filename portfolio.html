CS1310 – Computer Applications

Computer Basics

I learnt what a computer is, its main hardware parts (input, processing, storage and output devices), and how the hardware and software work together.

Bits, Bytes and Digital Data

I learnt that computers store all information as bits (0s and 1s), that 8 bits make one byte, and how text, images and sound are represented as digital data. I also learnt about units such as KB, MB, GB and TB.

Software and Licenses

I learnt the difference between system software and application software, and about software licenses such as proprietary, open source, freeware and shareware, which tell us how software may legally be used and shared.

Word Processing

I learnt to create and format documents using a word processor: fonts, paragraphs, headings, lists, tables, images and page layout.

Web Development with HTML

Through this assignment I am applying HTML to create linked web pages with headings, paragraphs, images, links and CSS styling.
